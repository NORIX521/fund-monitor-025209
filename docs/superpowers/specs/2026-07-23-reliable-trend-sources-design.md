# 可靠国内 / 国际趋势源设计

日期：2026-07-23

## 背景与根因

当前 `scripts/providers/news.py` 把资产中文名称、代码和中文板块原样用于国内、国际两个 Google News RSS 查询。国内查询可得到结果，但会混入财富号等用户内容；国际查询在 `en-US` 区域仍使用中文基金名与代码，实测稳定返回 0。模块注释称“allowlisted”，实际没有来源域名白名单、发布时间门槛或逐 feed 容错。

线上源数据目前仍有 3 条国内记录，截图中两列同时为空还可能叠加旧 Service Worker 缓存；但国际流为空与国内来源质量不足是数据提供层的真实问题，不能只靠刷新页面解决。

## 方案比较

### A. 官方来源池 + 本地化查询 + 容错（采用）

- 国内：工信部电子信息制造业运行数据作为直接官方源；Google News RSS 仅作为发现通道，结果必须来自工信部、发改委、中国政府网、证监会、上交所或深交所域名。
- 国际：按英文板块词查询，结果必须来自 SEMI、WSTS、美国商务部或 BIS 等行业机构/政府域名。
- 优点：零前端密钥、来源权威、保留现有 RSS 解析框架、能对单源失败降级。
- 代价：Google RSS 仍是部分国际内容的发现通道；官方站点或索引规则变化时需要维护适配器。

### B. 只把国际查询改成英文

- 优点：改动最小。
- 缺点：仍会混入低质量媒体和用户内容，不能满足“稳定可靠”。

### C. 商业新闻 API

- 优点：机器接口稳定、字段统一。
- 缺点：需要密钥、配额、费用和再分发授权；新闻聚合商也不等于第一方来源。

## 数据流

1. 根据资产名称、代码、市场和板块生成区域化检索词。`半导体/存储` 的国际词映射为 `semiconductor memory chip DRAM NAND HBM`，不再发送中文基金名。
2. 国内先读取工信部运行监测页面，挑选与电子信息制造业/集成电路相关的最新条目，并从文章元数据读取标题与发布时间。
3. 对每个区域依次请求多个 RSS feed；单个 feed 请求或 XML 解析失败时继续其余 feed。
4. 默认生产路径对来源主机、标题相关性和发布时间进行门禁；显式传入测试 feed 时保持纯解析能力，不触发外网官方源。
5. 去重后按发布时间倒序，最多保留 6 条；每条必须包含文章链接、发布者主页、发布时间、抓取时间和区域。
6. 若本轮无合格记录，沿用上一轮可信记录并把 source status 标为 stale；不得用空数组覆盖历史可信数据。

### 国际一级来源

- `www.semi.org` / `semi.org`
- `www.wsts.org` / `wsts.org`
- `www.commerce.gov` / `commerce.gov`
- `www.bis.gov` / `bis.gov`

默认只保留最近 120 天且标题命中板块关键词的记录。财富号等用户内容不再进入“可靠趋势”流。

## 错误处理

- 单 feed 失败：忽略该 feed，继续其他来源。
- 工信部列表或文章失败：不阻断 RSS 来源。
- 全部来源失败：返回空结果，由上层保留上次可信记录并显示 `no_reliable_update`。
- 时间、URL 或来源域名无效：丢弃该条，不把缺失来源包装为成功。

## 测试与验收

- RED：国际默认查询必须包含英文半导体词而不包含中文基金名；默认生产结果必须剔除未授权域名、过期和无关标题；单 feed 失败时另一个 feed 仍可返回；工信部条目能生成直接文章链接与发布时间。
- GREEN：上述定向测试通过，随后运行全部 Python、Node、输出契约与 YAML 检查。
- 实际抓取：当前 `025209` 在国内和国际区域均至少获得 1 条合格一级来源记录。
- 线上：GitHub Actions/Pages 成功，缓存破坏参数下两列可见，控制台无站点错误。

## 边界

- “可靠”指来源身份和溯源字段可靠，不代表内容观点正确或构成投资建议。
- 不保证每个资产每天都有新条目；没有新资料时保留上次可信记录并显示时间。
- 不在 GitHub Pages 前端存放 `MX_APIKEY` 或其他新闻 API 密钥。
